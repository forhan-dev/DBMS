## Oracle SQL `EXISTS` Operator

`EXISTS` is a **subquery operator** used to check whether a subquery returns **at least one row**.

### Basic idea

```sql
WHERE EXISTS (subquery)
```

Think of it as:

> **"Does at least one matching record exist?"**

* If the subquery returns **one or more rows** → `TRUE`
* If the subquery returns **zero rows** → `FALSE`

---

## Basic Syntax

```sql
SELECT column1, column2
FROM table1
WHERE EXISTS (
    SELECT 1
    FROM table2
    WHERE condition
);
```

`SELECT 1` is commonly used because we only care whether a row exists, **not what the row contains**.

---

## Simple Example

Suppose we have:

### `employees`

| employee_id | first_name | department_id |
| ----------: | ---------- | ------------: |
|         101 | John       |            10 |
|         102 | Smith      |            20 |
|         103 | David      |            30 |
|         104 | Anna       |            10 |

### `departments`

| department_id | department_name |
| ------------: | --------------- |
|            10 | IT              |
|            20 | HR              |
|            30 | Finance         |

Query:

```sql
SELECT first_name, department_id
FROM employees e
WHERE EXISTS (
    SELECT 1
    FROM departments d
    WHERE d.department_id = e.department_id
);
```

### What happens?

For John:

```text
Employee department_id = 10
        ↓
Does department 10 exist?
        ↓
YES
        ↓
John is returned
```

For Smith:

```text
Employee department_id = 20
        ↓
Does department 20 exist?
        ↓
YES
        ↓
Smith is returned
```

So `EXISTS` checks each employee against the subquery.

---

# `EXISTS` is usually used with a correlated subquery

A **correlated subquery** references a column from the outer query.

Example:

```sql
SELECT e.first_name
FROM employees e
WHERE EXISTS (
    SELECT 1
    FROM departments d
    WHERE d.department_id = e.department_id
);
```

Here:

```sql
e.department_id
```

comes from the **outer query**.

Therefore, the inner query depends on the current row of the outer query.

---

# `NOT EXISTS`

`NOT EXISTS` does the opposite.

It checks:

> **"Does no matching record exist?"**

Example:

```sql
SELECT e.first_name
FROM employees e
WHERE NOT EXISTS (
    SELECT 1
    FROM departments d
    WHERE d.department_id = e.department_id
);
```

This returns employees whose department **does not exist** in the `departments` table.
